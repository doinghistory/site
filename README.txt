歴史する：トップページ連携済み一式

このZIPは、アップロードされたClaude製トップページ index.html と、
今回作成した6ページを相互リンクした状態です。

構成
- index.html      Claude製トップページ（リンク変更済み）
- manabu.html     学ぶ
- tou.html        問う
- kitaeru.html    鍛える
- miru.html       観る
- shiraberu.html  調べる
- meguru.html     巡る
- 各ページで使用する画像ファイル

変更した主なリンク
- ヘッダーの「学ぶ / 問う / 鍛える / 観る / 調べる / 巡る」
- トップページ6セクションの「詳しく見る」
- 各セクション内の項目リンク
- 「時代をたどる」から manabu.html の該当時代へ
- 各詳細ページの「歴史する」から index.html#gates へ戻る

追加調整
- 「問う」のトップページ表記「用語チェック」を、今回決めた「一文論述」に変更
- 鍛える・調べる・巡るの一部項目は該当セクションへ直接ジャンプ

GitHub Pages
doinghistory/site リポジトリのルートへ、このZIPの中身をアップロードしてください。
既存 index.html はこの連携済み index.html で置き換える想定です。
