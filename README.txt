歴史する｜改訂版
================

主な修正
- 「このサイトについて」に相当するトップページの紹介セクションを削除
- 「最近追加した教材」は表示しない構成に統一
- 各ページのヘッダーを「学ぶ／問う／鍛える／観る／調べる／巡る」に統一
- ヘッダーの「歴史する」はトップページと同じ筆文字画像を使用
- Google Fonts 依存を外し、本文・見出しは端末標準の明朝／ゴシックを優先
- 英語の装飾ラベル、抽象的な短文コピー、機能しない仮リンクを削減
- 各ページの説明文を、教材サイトとして直接的な文体に変更

配置

- manabu.html（学ぶ）
- materials-a-v2.html（互換用）
- tou.html
- kitaeru.html
- miru.html
- shiraberu.html（調べる）
- meguru.html
- assets/logo.png

既存の背景画像（tou-hero.jpg など）は、現在のサイト側のファイルをそのまま使う想定です。
