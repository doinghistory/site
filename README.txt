歴史する：教材リンク連携版 v2

この版では「学ぶ」「問う」「観る」を同じ公開Googleスプレッドシートから読み込めるようにしました。

■ 共通データ元
site-config.js の SHEET_CSV_URL に設定済みです。

想定列
公開日 / 種別 / 時代 / タイトル / URL / ひとこと説明

■ 学ぶ
既存どおり、CSVの教材を自動表示します。
例：種別「プリント」「スライド」「資料」など。

■ 問う
CSVの「種別」に次の文字を含む行を自動表示します。
- 一問一答
- 一文論述
- 年代整序
URL列がそのまま教材リンクになります。

■ 観る
CSVの「種別」に「動画」を含む行を自動表示します。
- 「おすすめ」を含む → おすすめ動画
- それ以外の動画 → 授業動画
URL欄にYouTube URLを入れると、その場で再生できます。
任意列として「時間」「長さ」「提供」「出典」「チャンネル」も利用できます。

■ 問う：Webアプリ2つ
実URLがまだ不明のため、site-config.js の以下2箇所だけ未設定です。
- yamakawa
- jidaiToNagare

この2つの実URLを教えてもらえれば完成版にできます。
