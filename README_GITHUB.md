このフォルダの中身を、GitHub の `doinghistory/site` リポジトリの **ルート** に配置してください。`index.html` と６ページ（`manabu.html`, `tou.html`, `kitaeru.html`, `miru.html`, `shiraberu.html`, `meguru.html`）が同じ階層にあります。公開後は `https://doinghistory.github.io/site/` で確認できます。

トップと「学ぶ」「問う」「鍛える」「観る」は公開CSVを表示時に取得します。各行の「掲載先」を該当ページ名にし、公開を TRUE にします。未入力URLの行は「準備中」です。失敗時は2026年9月24日時点の内蔵データを表示します。スプシ更新は公開CSVの反映に伴い次の表示から読み込まれます。

「調べる」は公開資料サイトの登録データを `shiraberu-data.js` で管理します。「巡る」は `meguru-data.js` の見本記事を実際の記録や紹介文に差し替えてください。分類名はデータから自動で増えるため、「本・記事のこと」のように本やウェブ記事の紹介にも使えます。写真も見本で、クレジットはページ内にあります。

## 教材が増えたときの使い方

「学ぶ」「問う」「鍛える」「観る」の一覧は、教材名・説明・時代をキーワード検索できます。全角数字でも検索可能です。時代・種類との組み合わせ、公開済みのみ表示、授業順・新しい順・教材名順に対応し、20件ずつ表示します。検索条件を含むURLを生徒に共有できます。目次の「教材一覧へ」からは各ページの一覧に直接移動します。

教材をDrive等へアップロードしたら、生徒が閲覧できる共有設定にし、シートのURL列に閲覧用リンクを入れます。公開日は `2026/09/24` の形式、表示順は半角数字を推奨します。形式列は `PDF` など、実際の教材に合わせて入力してください。「授業順」はリンクのある教材を優先し、その中で表示順を使います。

シートの公開をFALSEにすると一覧から外れますが、公開CSVそのもののアクセス制限にはなりません。個人情報・採点情報などは公開シートに入れないでください。ファイルへのアクセス権はDrive等で別途管理します。

通信に失敗した場合は保存済み教材情報の日時と「再読み込み」を表示します。「公開済みのみ」は有効なリンクが登録された教材を指し、リンク先の閲覧権限やファイルの存在までは自動判定しません。

## 公開前の確認事項

- 2026年9月24日確認：「鎌倉幕府の成立年」の誤ったリンクを含む行は公開シートから削除済み。通信失敗時の予備データからも削除しました。動画の時代分類もシートに合わせて奈良に更新済みです。
- 「観る」の `VIDEO_ID` は仮のリンクのため表示されません。実際の動画URLに置き換えてください。
- URL未入力の教材は「準備中」です。
- 「巡る」の記録・写真は見本です。実際の原稿・写真に置き換えてください。
- 生徒のアカウントで教材を開けるか確認してください。この改修では共有権限は変更していません。

## 配置時の注意

ZIPを展開して **中のファイルと assets フォルダ** をリポジトリのルートにアップロードしてください。フォルダを一段余計に作るとページ間リンクが動きません。トップの見た目は既存版を維持しています。公開サイトの更新やGitHubへのpushはまだ行っていません。
